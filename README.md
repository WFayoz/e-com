# E-Com Backend API

E-Com is a RESTful backend API for an e-commerce platform built with FastAPI.  
It provides authentication, product catalog management, cart operations, checkout, order tracking, and role-based access for admins and customers.

## Features

- User registration and login
- JWT authentication
- Role-based access control: admin and customer
- Product catalog management
- Cart management
- Checkout and order creation
- Order tracking
- PostgreSQL database integration
- SQLAlchemy ORM models
- Swagger/OpenAPI documentation
- Keeps code on Redis
  

## Tech Stack

- Python
- FastAPI
- PostgreSQL
- SQLAlchemy
- JWT
- Docker
- Git / GitHub
- Redis
